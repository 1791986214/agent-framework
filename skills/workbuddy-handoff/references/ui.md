# WorkBuddy 界面操作（仅使用桌面界面时读取）

1. 每次操作前取新鲜界面状态；核对项目、会话标题、当前模型、工作区和输入栏。节点索引可能变化，不沿用旧索引。
2. 优先用支持 Unicode 的粘贴。输入异步更新时先等稳定；确认完整草稿和发送按钮状态后再发送。若界面有文本而应用未识别输入，重新聚焦或渲染输入栏再检查。
3. 发送后确认请求在目标会话可见。状态不明先检查已有消息和草稿，不重复派发。无法正确输入中文时，可用语义完整的英文派发，但保留路径与步骤合同。
4. 项目文件可由获准的文件工具读取时，用路径和差异审查；界面只用于交接或必须的真实界面验收。优先定向状态，必要时才取完整状态或截图。
