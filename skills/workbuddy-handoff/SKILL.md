# WorkBuddy 交接

WorkBuddy 是执行平台，不是可由通用子智能体工具任意指定的模型。沿用当前主模型；在 WorkBuddy 中核实目标项目、会话、模型及可见强度，不能把旧配置或角色名称当作实际参数。用户要“继续那个会话”时先核对标题与内容；新任务才新建会话。

读取本任务固定提交的 [共享规则](https://github.com/1791986214/agent-framework/blob/main/AGENTS.md) 和项目约定。每次只交接一个已规划步骤；派发内容给出唯一任务文档绝对路径、步骤编号、允许写入范围、交付物与必需验证。执行者只写本步记录和完成勾选。发送前核对草稿与配置，发送后确认请求确实出现在目标会话，避免重复派发。

优先用可用的专用接口；只有必要时使用桌面界面，界面细节见 [按需操作说明](references/ui.md)。等待完成通知或做低频、有界检查，不反复获取整页状态/截图。外部执行迟迟无结果时记录实际阻塞，不无限轮询。

主智能体核对产物、原始证据和进度文档的**实际勾选状态**；执行记录自称完成但勾选未落盘时，退回同一步修正，不能代勾或验收。仅记录平台实际可见的 token/积分与耗时，积分不可换算成 token，缺失用量不估计。
