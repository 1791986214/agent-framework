# 主智能体调用子智能体

把调用语句后的文字作为任务直接执行，不要求用户填表，也不只解释流程。

1. 读取 [共享规则](https://github.com/1791986214/agent-framework/blob/main/AGENTS.md)，记录本次实际提交 SHA；再读目标项目适用规则和唯一任务文档。规则库在业务任务中只读。
2. 沿用当前主模型；角色名不能切换模型。核实委派工具是否支持用户指定的子模型/强度，按实际参数调用，不能支持就如实说明。
3. 按共享规则规划最少的完整步骤，串行派发并独立验收，直到完成或有具体阻塞。可隔离旧会话历史，但每步派发仍须自足。

用户指定 WorkBuddy 时，另读 [WorkBuddy 交接技能](../workbuddy-handoff/SKILL.md)。
