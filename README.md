# 多平台智能体协作框架

版本 0.4。日常执行只需读取 [AGENTS.md](AGENTS.md) 和当前任务的唯一进度文档；[模板](templates/TASK.md) 可选。工程验证、WorkBuddy 界面操作及用量对照只在相应任务中读取对应参考文件。

一句话启动：

> `<主智能体>调用<子智能体>：<目标与约束>`

例如：`Sol 调用 Luna：核对当前项目清单，规划并完成未验收步骤。` 主模型由平台当前选择决定；要指定子模型或强度就在请求中写明。仓库附带的 [Codex 触发技能](skills/main-calls-subagent/SKILL.md) 可安装到本地技能目录；公开 GitHub 文件本身不会自动注册技能。

## 文件放置与版本

- **规则仓库**：多平台可读，业务任务只读。任务开始时记录实际提交 SHA，并在该任务内固定版本；不依赖随时变化的 `main`。
- **任务文档**：放在获准写入的工作区，主智能体规划/审查，子智能体只回填本步执行项。不同平台不会自动同步同一文件，交接时先同步并移交写入权。
- **目标项目**：代码、测试和合同文档在项目自身授权范围内修改；项目 `AGENTS.md` 和业务不变量仍适用。

公开仓库便于各平台读取，不应放客户资料、凭据或具体任务进度。归档仓库可防常规远端写入；本地只读限制须由平台或文件系统实际实施，文字规则不等于权限隔离。用户明确要求维护时，解除归档、提交新版本并重新归档。旧任务继续使用旧提交，新任务固定新提交。

## 减少上下文

入口只保留不可省的执行边界。按相关步骤读取文件、差异和失败片段，不把整段会话、全量仓库或长日志反复交给模型。用完成通知或低频有界等待；主智能体保留独立验收。官方计量中缓存输入属于输入总量，仍产生用量；详见 [计量说明](references/measurement.md)。
